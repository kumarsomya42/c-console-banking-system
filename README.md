# C Console Banking System
A simple, lightweight command-line banking applicationwritten in C. This project manages multiple users using parallel arrays, secure PIN authentication, and basic financial transactions (deposits, withdrawals,and balance checks).

## Features
* **Multi-User Support:** Create and manage up to 5 user accounts.
* **PIN Authentication:** Secure access to individual accounts using a unique PIN.
* **Core Banking Operations:**
  * Check current balance
  * Deposit funds
  * Withsraw funds
* **Interactive CLI Menu:** Smooth navigation loops allowing users to perform multiple actions before logging out.
